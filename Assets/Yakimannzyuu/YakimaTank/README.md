# YakimaTank

VRChat のワールドで、戦車モデルを簡単なセットアップで走行・射撃できるようにする Udon ギミックです。

> 開発中です。仕様や構成は予告なく変わります。

## 動作環境

- Unity 2022.3
- VRChat Worlds SDK 3.10.0 以降(UdonSharp を含む)

## 導入方法(開発中の版)

VCC での配布は正式リリース時に用意します。それまでは Unity Package Manager の git URL で導入できます。

1. VRChat Worlds SDK を入れたワールドプロジェクトを Unity で開く
2. Window → Package Manager を開く
3. 左上の「+」→ Add package from git URL を選ぶ
4. 次の URL を入力して Add を押す

```
https://github.com/yakimannzyuu/YakimaTank.git?path=/Assets/Yakimannzyuu/YakimaTank
```

特定の版に固定したいときは、URL の末尾に `#<コミットハッシュ>` を付けます。

## 使い方

戦車に乗り、Desktop と VR で走らせ（前進・後退・旋回・制動）、砲塔と砲身を回して撃てます。車体の位置と向き、砲塔の角度と発射は、ほかの人の画面にも同期します。車両同士はぶつかると止まります。砲弾が当たると相手の HP が減り、0 で破壊され、しばらくすると最初の位置で復活します。

始める前に、VRChat SDK の Control Panel の Builder でレイヤーの設定（Setup Layers）を済ませてください。戦車とプレイヤーの当たりを外すのに、VRChat の標準のレイヤー `Walkthrough` を使います。ないと「検証」が Error になります。

1. メニューの **Tools → YakimaTank → Setup** を開く
2. 「新しい設定アセットを作る」で設定アセットを作る（設定アセットが正本です。生成で作る部分（コライダー・転輪・車両の値）を Prefab で直接直しても、次の生成で設定の値に戻ります）
3. 「モデル」に戦車のモデル（FBX や Prefab）を入れる
   - モデルの前が +Z、上が +Y でなければ、「Model Rotation」で補正する
4. 「対応」で、車体・左右の転輪・砲塔・砲身をモデルの階層から選ぶ（砲塔と砲身は必須。砲身は砲塔の下（子孫）にあること。座席は砲塔の上に付いて行きます）
   - 砲口は、砲身の下に名前に「Muzzle」を含む GameObject があればその位置、なければ砲身のメッシュの前の端です
   - 砲塔と砲身をボーン（Armature）で回すモデル（メッシュがボーンの下にないモデル）は、砲塔と砲身にボーン（例：`TurretPivot`・`GunPivot`）を選び、砲身のボーンの下に砲口の印（例：`GunPivot/Gun/Muzzle`）を置いてください。ボーンを Animator で動かしていると、砲塔の向きが上書きされます
5. 必要なら走行と足回りの値を直す。転輪の半径とサスペンションの強さは、0 のままならモデルと質量から求めます
   - 「生成」は、その時点のウィンドウの値を設定アセットに保存してから動きます。配置は、初回に決めた位置と配置 ID だけを設定アセットに保存します
6. 「検証」で Error がないことを確かめ、「生成」を押す。出力先の Prefab ができます
   - 出力先にこのツールで作っていない Prefab があると、上書きせずに Error にします
7. 「今のシーンに配置・更新」を押す。最初のスポーン地点の前方の床に 1 台置き、シーンを保存すると残ります
   - 2 回目からは同じ車両をそのまま使います。置いた車両を手で直していたら、変えずに止めて理由を出します
   - 配置のたびに、シーンの車両の一覧（`YakimaTank_Automation/YakimaTankVehicleRegistry`）を作り直します

生成 Prefab には、座席（VRCStation）・乗車の判定・Desktop と VR の入力・武器（`Weapon`。砲弾を含む）・命中用のトリガー・生存の状態（HP）と HP のバーが入っています。車体のコライダーと WheelCollider は `Walkthrough` レイヤーに置くので、プレイヤーは戦車をすり抜けます（壁や地面とは当たります）。元のモデルにトリガーでないコライダーがあると、生成 Prefab の中で無効にします（元のアセットは変えません。検証で一覧を Warning に出します）。

誰も座っていない間は、ほかの Udon から車両の `SetDriveInput(throttle, steer, brake)` を呼んで走らせることもできます（throttle・steer は -1〜1、brake は 0〜1。steer が正なら右へ回ります）。効くのは車両のオーナーの画面だけです。

### 乗り方・降り方

- 戦車に近づいて Interact（車体の周りの、砲塔の高さまでが乗車の判定です）すると、砲塔の上の座席に座ります。誰かが座っている間は、判定が光らなくなります。
- 降りるときは、Desktop は Space、VR はジャンプ。運転の W・A・S・D（VR はスティック）では降りません。その場で降り、戦車をすり抜けて地面に立ちます。降りると、戦車は停止中のブレーキで止まります。

### 複数人で使うとき

- 乗った人が車両のオーナーになり、その人の画面で走行を計算して、位置・向き・速度を送ります。ほかの人の画面では、届いた状態を少し遅らせて滑らかにつないで見せます。
- 座ってからオーナーになるまでは操作できません。3 秒たってもオーナーになれないとき、座ったままほかの人がオーナーになったときは、座席から降ろします。
- 降りてもオーナーはそのままで、次に乗った人がオーナーになります。オーナーがインスタンスから抜けると、VRChat が決めた次のオーナーが、最後の状態から引き継ぎます。
- 止まった戦車は、後から入った人の画面でも最後の位置に見えます。誰かが乗っている間は、後から入った人の画面でも乗車の判定が光りません。
- 車両同士の当たりは、シーンの車両の一覧を使います。
  - 配置で置いた車両は、自動で一覧に入ります。生成 Prefab を手でシーンに置いたときは、ウィンドウの「シーンの車両一覧を更新」を押してください。
  - 一覧が実際の車両と合わないと、ウィンドウに Warning を出し、VRChat SDK のビルドを止めます（ログに理由が出ます）。一覧がないまま動かすと、車両同士はぶつからず、同じ人がオーナーの車両同士は通常の物理で当たります。
- 送る間隔（既定 0.1 秒）と、届かないときに先へ進めて見せる上限（既定 0.25 秒）は、設定の「同期」で直せます（今の値は仮です）。

### 撃つ

- 撃てるのは、座っていて、車体と武器（`Weapon`）の両方のオーナーになっているときだけです。座ると両方の所有権を取ります。
- 砲弾は同期しません。撃った人の画面の砲弾だけが、当たった車両を数えます。ほかの人の画面の砲弾は見た目です。
- 砲弾は、壁（トリガーでないコライダー）と、ほかの車両の命中用のトリガー（車体と砲塔に 1 つずつ、`Default` のトリガー）で止まります。自分の車両・乗車の判定・プレイヤーは通り抜けます。
- 弾数は無限で、装填の時間（既定 3 秒）ごとに撃てます。回る速さ（砲塔 30 度/秒・砲身 15 度/秒）・砲身の上下の範囲（-10〜+20 度）・弾速（200 m/s）・重力・寿命（3 秒）・装填の時間は、設定の「砲塔・武器」で直せます（今の値は仮です）。装填の時間は、同期の送る間隔より長くします。
- ほかの人の画面では、通信が詰まると、発射の表示が欠けることがあります。オーナーが代わる前後は、砲塔の向きと発射の表示が一時的にずれることがあります。
- 発射の閃光と音はまだありません。

### HP・破壊・復活

- 自分の砲弾がほかの車両に当たると、撃った人の画面から、その車両のオーナーへ命中を知らせます。オーナーが確かめて HP を減らし、ほかの人の画面にも送ります。同じ命中は 2 回数えません。
- 減る量は、撃った車両の「1 発のダメージ」（既定 25）です。最大 HP（既定 100）なので、既定では 4 発で破壊されます。
- HP が 0 になると破壊です。座っている人は降り、乗れなくなり、走れず撃てません。破壊の見た目（煙など）はまだありません。
- 破壊から復活の待ち時間（既定 5 秒）がたつと、最初の位置で復活します。HP は最大に、砲塔と砲身の角度と装填は初期値に戻ります。
- 車両の上（モデルの上端より 0.6 m 上）に HP のバーが出ます。どの向きからも見えます。バーの色は、出力先のフォルダにできる材質（`YakimaTankHealthBack.mat`・`YakimaTankHealthFill.mat`）で変えられます。
- 最大 HP・1 発のダメージ・復活の待ち時間は、設定の「HP・復活」で直せます（今の値は仮です）。Play 中に最大 HP を変えると、次の復活から効きます。
- 命中を知らせる前に相手のオーナーが代わると、その命中は数えられません。
- 同じ車両から撃った弾は、後に撃った弾が先に当たると、前に撃った弾の命中を数えません（同じ命中を 2 回数えないための決まり）。装填の時間を砲弾の寿命より短くしたときに起きることがあります。
- 確かめるのは、知らせた人がその時点で撃った車両の武器のオーナーかどうかまでです。武器のオーナーが、撃っていない命中を知らせること（改造したクライアントなど）は防げません。
- HP の部品がない古い生成物は、「生成」をやり直すと足されます。HP の部品を足す前にビルドしたシーンでは、車両に記録した Network ID の型が古くなりますが、配置・「シーンの車両一覧を更新」・VRChat SDK のビルドの前の確かめで外れます（外したらシーンを保存してください）。

### 車両同士がぶつかったとき

- 各オーナーが、自分の車両の速度だけを直します。相手へ寄る分を止め、重なった深さに応じて少し押し返します。相手の車両を直接動かすことはありません。少しのめり込みは残ります。
- 当たる位置は、相手の最新の状態を今の時刻まで進めた位置です。相手の見た目（少し遅らせて表示している）より、少し先で当たります。相手が速いほど違いが大きくなります。
- 相手の状態が届かなくなって 1 秒より古くなると（止まった印がない場合）、その相手とはぶつかりません。
- 止まった車両を押せるのは、押す側の駆動が、押される側のブレーキより強いときだけです。既定値（駆動のトルク 12000・停止中のブレーキのトルク 20000）では、全開で当てても止まった戦車は動かず、当てた側が止まります。止まった戦車を押せるようにしたいときは、「走行」の停止中のブレーキのトルク（Idle Brake Torque）を、駆動のトルク（Drive Torque）より小さくしてください（降りた後に止まるまでが長くなります）。乗ってブレーキを踏んでいる戦車は押されません。
- 横から当てても、相手は横には動きません（タイヤの横の摩擦で受けます）。
- 止める速さ（既定 10）・押し返す強さ（既定 20）・押す加速の上限（既定 5 m/s²）は、設定の「接触」で直せます（今の値は仮です）。

### Desktop の操作

| 入力 | 動き |
|---|---|
| W | 前進 |
| S | 押している間だけ後退（前進中は、まず止まってから後退） |
| A / D | 左 / 右へ旋回（アクセルを離しても、旋回中は惰性で進む） |
| 視点（マウス） | 見た方へ砲塔と砲身が向く（回る速さで追いかける。砲身の上下は範囲で止まる） |
| 左クリック | 撃つ（装填が終わっていれば。押し続けると装填ごとに 1 発） |
| Space | 降りる |

### VR の操作

左手で走行、右手で砲と射撃。グリップを握った瞬間の手の位置と向きが基準になります。

| 入力 | 動き |
|---|---|
| 左グリップ＋手首を左右にひねる | 旋回 |
| 左グリップ＋手前に引く | 後退のギア（引いたまま左トリガーで後退） |
| 左トリガー | アクセル（アナログ） |
| 左グリップを離す | 旋回をやめ、ギアを前進に戻す |
| 右グリップ＋ひねる | 砲塔を左右に回す（ひねった量で速さが変わる） |
| 右グリップ＋前後 | 砲身を上下に回す（前で上） |
| 右トリガー | 撃つ（装填が終わっていれば） |
| ジャンプ | 降りる |

ブレーキの入力はありません。トリガーを離し、ひねってもいなければ止まります。グリップを握ったとみなす値・ねじりの最大角・前後の最大距離・後退のしきい値・不感帯は、設定の「操作（VR）」で直せます（今の値は仮です）。

### デバッグ UI

パッケージの `Runtime/YakimaTankDebugPanel.prefab` をシーンに置き、「Vehicle」に表示する車両を指定すると、ハンドル・レバー・アクセル・前進後退・ギア・砲の入力・射撃を箱の大きさで見られます。下の欄には同期の状態が出ます。

- 既定は車両に付いて行きます（「Follow Position・Follow Rotation」が車体から見た位置と向き）。「Follow Vehicle」を外すと、置いた場所に留まります。
- 表示は各自の画面だけです。乗っていない人の画面では、操作の値は初期値のままです。
- 同期の欄：`OWNER`（自分の画面で計算している）か `REMOTE`、Owner（オーナーのプレイヤー ID。自分なら `(you)`）、Driver（運転手の ID。いなければ `-`）、Epoch（世代。所有権を取ったときと最初の位置に戻したときに進む）、オーナーなら Sent/s と Req/s（実際に送った回数と要求した回数、毎秒）と Contact・Stale（重なっている相手の数と、状態が古くてぶつからない相手の数）と Bytes（車体・武器・HP の同期が最後に送った大きさ、バイト。VRChat の値で、Unity の Play では 0 か仮の値。部品がなければ `-`）、オーナー以外なら Age（最新の状態の古さ、秒）、Rejected（使わなかった状態の数）。
- 文字は英字だけです（日本語のフォントを同梱しないため）。

### 演出を作るとき

車体の同期の Udon（`YakimaTankVehicleSync`。ルート）の `_GetDisplayVelocity()` と `_GetDisplayAngularVelocity()` が、表示用の速度と角速度（ワールドの向き、m/s・rad/s）を返します。履帯・転輪・エンジンの音などを、各自の画面で出すときに使えます（同期は増えません）。

- オーナーの画面：Rigidbody の値
- ほかの人の画面：最新の受けた状態の値（見えている位置より少し先の値）。止まった状態を受けた後、状態が届かなくなって見た目も止まった後、まだ状態を受けていないときは 0

### Play 中の調整

Play 中は、ウィンドウの「Play 中の調整」で値を試せます。走行の値のほか、座席のずらし（砲塔の上面の中央からのずれ。アバターの大きさに合わせる）、VR の操作の値、同期と接触の値、砲塔・武器の値、HP・復活の値も試せます。

- **再適用**：作業値を車両に書き、最初の位置に戻す
- **出し直し**：車両を作り直して作業値で置き直す
- **作業値を設定に保存**：試した値を設定アセットに書く。Play を出たら「生成」をやり直すと、Prefab に入ります

作業値は、保存するまで設定アセットに書きません。

## 更新方法

Unity は導入したコミットを `Packages/packages-lock.json` に記録します。そのため、リポジトリが更新されても、Unity を再起動しただけでは導入済みの版は変わりません。

最新版にするには、上の導入方法の手順 3・4 で同じ URL をもう一度指定します。コミットハッシュを付けて固定していた場合は、それを外すか、更新先のハッシュに変えてください。
