# YakimaTank

VRChat のワールドで、戦車モデルを簡単なセットアップで走行・射撃できるようにする Udon ギミックです。

> 開発中です。仕様や構成は予告なく変わります。

## 動作環境

- Unity 2022.3
- VRChat Worlds SDK 3.10.0 以降(UdonSharp を含む)

## 導入方法(開発中の版)

VCC での配布は正式リリース時に用意します。それまでは Unity Package Manager の git URL で導入できます。

1. VRChat Worlds SDK を入れたワールドプロジェクトを Unity で開く
2. Window → Package Manager を開く
3. 左上の「+」→ Add package from git URL を選ぶ
4. 次の URL を入力して Add を押す

```
https://github.com/yakimannzyuu/YakimaTank.git?path=/Assets/Yakimannzyuu/YakimaTank
```

特定の版に固定したいときは、URL の末尾に `#<コミットハッシュ>` を付けます。

## 使い方

いまできるのは走行（前進・後退・旋回・制動）までです。砲塔の操作・射撃・同期・乗車と入力の割り当ては、まだありません。

1. メニューの **Tools → YakimaTank → Setup** を開く
2. 「新しい設定アセットを作る」で設定アセットを作る（設定アセットが正本です。生成で作る部分（コライダー・転輪・車両の値）を Prefab で直接直しても、次の生成で設定の値に戻ります）
3. 「モデル」に戦車のモデル（FBX や Prefab）を入れる
   - モデルの前が +Z、上が +Y でなければ、「Model Rotation」で補正する
4. 「対応」で、車体と左右の転輪をモデルの階層から選ぶ（砲塔と砲身は記録だけで、まだ使いません）
5. 必要なら走行と足回りの値を直す。転輪の半径とサスペンションの強さは、0 のままならモデルと質量から求めます
   - 「生成」と「今のシーンに配置・更新」は、その時点のウィンドウの値を設定アセットに保存してから動きます
6. 「検証」で Error がないことを確かめ、「生成」を押す。出力先の Prefab ができます
7. 「今のシーンに配置・更新」を押す。最初のスポーン地点の前方の床に 1 台置き、シーンを保存すると残ります
   - 2 回目からは同じ車両をそのまま使います。置いた車両を手で直していたら、変えずに止めて理由を出します

走らせるには、ほかの Udon から車両の `SetDriveInput(throttle, steer, brake)` を呼びます（throttle・steer は -1〜1、brake は 0〜1。steer が正なら右へ回ります）。

### Play 中の調整

Play 中は、ウィンドウの「Play 中の調整」で値を試せます。

- **再適用**：作業値を車両に書き、最初の位置に戻す
- **出し直し**：車両を作り直して作業値で置き直す
- **作業値を設定に保存**：試した値を設定アセットに書く。Play を出たら「生成」をやり直すと、Prefab に入ります

作業値は、保存するまで設定アセットに書きません。

## 更新方法

Unity は導入したコミットを `Packages/packages-lock.json` に記録します。そのため、リポジトリが更新されても、Unity を再起動しただけでは導入済みの版は変わりません。

最新版にするには、上の導入方法の手順 3・4 で同じ URL をもう一度指定します。コミットハッシュを付けて固定していた場合は、それを外すか、更新先のハッシュに変えてください。
