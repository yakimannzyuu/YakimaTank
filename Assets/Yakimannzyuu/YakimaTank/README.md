# YakimaTank

VRChat のワールドで、戦車モデルを簡単なセットアップで走行・射撃できるようにする Udon ギミックです。

> 開発中です。仕様や構成は予告なく変わります。

## 動作環境

- Unity 2022.3
- VRChat Worlds SDK 3.10.0 以降(UdonSharp を含む)

## 導入方法(開発中の版)

VCC での配布は正式リリース時に用意します。それまでは Unity Package Manager の git URL で導入できます。

1. VRChat Worlds SDK を入れたワールドプロジェクトを Unity で開く
2. Window → Package Manager を開く
3. 左上の「+」→ Add package from git URL を選ぶ
4. 次の URL を入力して Add を押す

```
https://github.com/yakimannzyuu/YakimaTank.git?path=/Assets/Yakimannzyuu/YakimaTank
```

特定の版に固定したいときは、URL の末尾に `#<コミットハッシュ>` を付けます。

## 使い方

いまできるのは、1 人で戦車に乗り、Desktop と VR で走る（前進・後退・旋回・制動）ことまでです。砲塔の操作・射撃・同期は、まだありません。同期しないので、ほかの人の画面では戦車は動きません。

始める前に、VRChat SDK の Control Panel の Builder でレイヤーの設定（Setup Layers）を済ませてください。戦車とプレイヤーの当たりを外すのに、VRChat の標準のレイヤー `Walkthrough` を使います。ないと「検証」が Error になります。

1. メニューの **Tools → YakimaTank → Setup** を開く
2. 「新しい設定アセットを作る」で設定アセットを作る（設定アセットが正本です。生成で作る部分（コライダー・転輪・車両の値）を Prefab で直接直しても、次の生成で設定の値に戻ります）
3. 「モデル」に戦車のモデル（FBX や Prefab）を入れる
   - モデルの前が +Z、上が +Y でなければ、「Model Rotation」で補正する
4. 「対応」で、車体・左右の転輪・砲塔をモデルの階層から選ぶ（座席は砲塔に置きます。砲塔を選ばないと車体に置き、Warning を出します。砲身は記録だけで、まだ使いません）
5. 必要なら走行と足回りの値を直す。転輪の半径とサスペンションの強さは、0 のままならモデルと質量から求めます
   - 「生成」は、その時点のウィンドウの値を設定アセットに保存してから動きます。配置は、初回に決めた位置と配置 ID だけを設定アセットに保存します
6. 「検証」で Error がないことを確かめ、「生成」を押す。出力先の Prefab ができます
   - 出力先にこのツールで作っていない Prefab があると、上書きせずに Error にします
7. 「今のシーンに配置・更新」を押す。最初のスポーン地点の前方の床に 1 台置き、シーンを保存すると残ります
   - 2 回目からは同じ車両をそのまま使います。置いた車両を手で直していたら、変えずに止めて理由を出します

生成 Prefab には、座席（VRCStation）・乗車の判定・Desktop と VR の入力が入っています。車体のコライダーと WheelCollider は `Walkthrough` レイヤーに置くので、プレイヤーは戦車をすり抜けます（壁や地面とは当たります）。元のモデルにトリガーでないコライダーがあると、生成 Prefab の中で無効にします（元のアセットは変えません。検証で一覧を Warning に出します）。

誰も座っていない間は、ほかの Udon から車両の `SetDriveInput(throttle, steer, brake)` を呼んで走らせることもできます（throttle・steer は -1〜1、brake は 0〜1。steer が正なら右へ回ります）。

### 乗り方・降り方

- 戦車に近づいて Interact（戦車全体が乗車の判定です）すると、砲塔の上の座席に座ります。誰かが座っている間は、判定が光らなくなります。
- 降りるときは、Desktop は Space、VR はジャンプ。その場で降り、戦車をすり抜けて地面に立ちます。降りると、戦車は停止中のブレーキで止まります。

### Desktop の操作

| 入力 | 動き |
|---|---|
| W | 前進 |
| S | 押している間だけ後退（前進中は、まず止まってから後退） |
| A / D | 左 / 右へ旋回（アクセルを離しても、旋回中は惰性で進む） |
| 視点（マウス） | 砲の左右・上下の入力（この版では表示だけ） |
| 左クリック | 射撃の入力（この版では表示だけ） |
| Space | 降りる |

### VR の操作

左手で走行、右手で砲と射撃。グリップを握った瞬間の手の位置と向きが基準になります。

| 入力 | 動き |
|---|---|
| 左グリップ＋手首を左右にひねる | 旋回 |
| 左グリップ＋手前に引く | 後退のギア（引いたまま左トリガーで後退） |
| 左トリガー | アクセル（アナログ） |
| 左グリップを離す | 旋回をやめ、ギアを前進に戻す |
| 右グリップ＋ひねる・前後 | 砲の左右・上下の入力（この版では表示だけ） |
| 右トリガー | 射撃の入力（この版では表示だけ） |
| ジャンプ | 降りる |

ブレーキの入力はありません。トリガーを離し、ひねってもいなければ止まります。グリップを握ったとみなす値・ねじりの最大角・前後の最大距離・後退のしきい値・不感帯は、設定の「操作（VR）」で直せます（今の値は仮です）。

### デバッグ UI

パッケージの `Runtime/YakimaTankDebugPanel.prefab` をシーンに置き、「Vehicle」に表示する車両を指定すると、ハンドル・レバー・アクセル・前進後退・ギア・砲の入力・射撃を箱の大きさで見られます。

- 既定は車両に付いて行きます（「Follow Position・Follow Rotation」が車体から見た位置と向き）。「Follow Vehicle」を外すと、置いた場所に留まります。
- 表示は各自の画面だけです。乗っていない人の画面では初期値のままです。
- 文字は英字だけです（日本語のフォントを同梱しないため）。

### Play 中の調整

Play 中は、ウィンドウの「Play 中の調整」で値を試せます。走行の値のほか、座席のずらし（砲塔の上面の中央からのずれ。アバターの大きさに合わせる）と VR の操作の値も試せます。

- **再適用**：作業値を車両に書き、最初の位置に戻す
- **出し直し**：車両を作り直して作業値で置き直す
- **作業値を設定に保存**：試した値を設定アセットに書く。Play を出たら「生成」をやり直すと、Prefab に入ります

作業値は、保存するまで設定アセットに書きません。

## 更新方法

Unity は導入したコミットを `Packages/packages-lock.json` に記録します。そのため、リポジトリが更新されても、Unity を再起動しただけでは導入済みの版は変わりません。

最新版にするには、上の導入方法の手順 3・4 で同じ URL をもう一度指定します。コミットハッシュを付けて固定していた場合は、それを外すか、更新先のハッシュに変えてください。
