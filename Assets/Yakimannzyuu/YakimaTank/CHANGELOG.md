# 変更履歴

新しい版を一番上に足す。見出しは `## [x.y.z] - YYYY-MM-DD` の形にする。

## [0.2.0] - 2026-11-14

### 追加

- 乗車と降車：戦車と同じ大きさの乗車の判定を Interact すると、砲塔の上の座席（VRCStation）に座る。誰かが座っている間は判定を無効にする。降りるのは VRCStation の標準（Desktop は Space、VR はジャンプ）で、その場で降りる
- 共通操作値（`YakimaTankControlState`）：入力の方法と車両の動きを分ける値。自分が座っている間、車両はアクセル × ギアで走る
- Desktop の操作：W・S で前進・後退、A・D で旋回、視点で砲の入力、左クリックで射撃の入力（砲と射撃は表示だけ）
- VR の操作：左グリップ＋ひねりで旋回、手前に引いて後退のギア、左トリガーでアクセル。右手で砲と射撃の入力（表示だけ）
- デバッグ UI（`Runtime/YakimaTankDebugPanel.prefab`）：共通操作値を箱の大きさで見せる。車両に付いて行くか、置いた場所に留まるかを選べる
- 設定：座席のずらしと、VR の操作の調整値。どちらも Play 中に再適用できる

### 変更

- 設定アセットの版を 2 にした。版 1 の設定は、開いたときに版 2 へ移る（走行・足回りの値と参照はそのまま、足した項目は既定値）。ファイルに書き戻すのは、次に保存したとき
- 生成：車体のコライダーと WheelCollider を `Walkthrough` レイヤーに置き、プレイヤーと当たらないようにした。VRChat のレイヤーの設定がないと検証で Error になる
- 生成：元のモデルのトリガーでないコライダーを、生成 Prefab の中で無効にする（元のアセットは変えない）。検証で一覧を Warning に出す
- 検証：砲塔の対応がないと Warning（座席を車体に置く）。「砲塔は記録だけ」の Warning はなくした
- 配置：入れ物の中の車両を、子の順番ではなく生成 Prefab のインスタンスで見分ける。その車両を指すデバッグ UI を 1 枚まで許す（ほかの追加物は今までどおり止める）

### 未実装

- 砲塔の操作・射撃・同期（この版は各自の画面だけで動く）

## [0.1.0] - 2026-11-13

### 追加

- 車両の走行（`YakimaTankVehicle`）：前進・後退・旋回・制動、最高速度、設定の再適用と最初の位置への戻し
- セットアップウィンドウ（Tools → YakimaTank → Setup）と設定アセット：モデルの階層から車体と転輪を選び、検証して生成する
- 生成 Prefab：元のモデルを入れ子のまま置き、Rigidbody・車体の BoxCollider・転輪ごとの WheelCollider・車両の Udon を足す。生成し直しても GUID と中のオブジェクトを保ち、保存の後の確認で失敗したら前の Prefab に戻す。出力先にこのツールで作っていない Prefab があれば上書きしない
- シーンへの配置：最初のスポーン地点の前方に 1 台置く。2 回目からは同じ車両を使い、手で直した所があれば変えずに止める
- Play 中の調整：再適用・出し直し・作業値を設定に保存

### 未実装

- 砲塔の操作・射撃・同期・乗車と入力の割り当て（砲塔と砲身は設定に記録するだけ）
