# 変更履歴

新しい版を一番上に足す。見出しは `## [x.y.z] - YYYY-MM-DD` の形にする。

## [0.5.0] - 2026-11-17

### 追加

- 砲塔と砲身（`YakimaTankWeaponSync`）：Desktop は見た方へ砲塔と砲身が向き、VR は右手のねじり・前後の量で回す。砲身の上下は範囲で止まる。砲塔の角度は、ほかの人の画面にも同期する
- 装填と射撃：装填が終わっていれば撃てる（押し続けると装填ごとに 1 発）。弾数は無限。撃つと、ほかの人の画面にも見た目の砲弾が出る（通信が詰まると欠けることがある）
- 砲弾（`YakimaTankShell`）：同期せず、各自の画面で弾速と重力で飛ぶ。壁で止まり、ほかの車両の命中用のトリガー（`YakimaTankHitbox`。車体と砲塔に 1 つずつ）で止まる。撃った人の画面で、当たった車両が分かる（まだ HP には効かない）
- 設定：「砲塔・武器」の回る速さ・砲身の上下の範囲・弾速・重力・寿命・装填の時間。どれも Play 中に再適用できる
- 武器の所有権：ルートの子の `Weapon` に置き、車体とは別に所有権を持つ。座ると両方の所有権を取り、両方そろってから操作できる

### 変更

- 設定アセットの版を 5 にした。版 1〜4 の設定は、開いたときに版 5 へ移る（前の値と参照はそのまま、足した項目は既定値）。ファイルに書き戻すのは、次に保存したとき
- 対応：砲塔と砲身が要る（ないと検証で Error）。砲身は砲塔の下（子孫）にあること。砲塔の対応がないときに座席を車体に置く Warning と、「砲身は記録だけ」の Warning はなくした
- 座席：砲塔の子から、ルートの下に移した。砲塔の下に位置の参照（`SeatAnchor`）を置き、座席は位置だけ付いて行く（向きは車体のまま。座った人は砲塔と一緒に回らない）。座席のずらしは、砲塔から見た向きになる。前に生成した車両は、「生成」をやり直すと座席がルートの下へ移る（座席のオブジェクトは保つ）
- 砲口：砲身の下に名前に「Muzzle」を含む GameObject があれば、その位置。なければ砲身のメッシュの前の端。砲塔と砲身をボーン（Armature）で回すモデルは、砲身のボーンの下に、この砲口の印を置く
- 生成：`Weapon`（武器の同期・砲弾）、命中用のトリガー、座席の位置の参照、砲口を足す。見た目の砲弾の材質（`YakimaTankShell.mat`）を出力先のフォルダに作る
- シーンの車両の一覧：始まるときに、各車両へ一覧の中の番号を知らせる

### 未実装

- 命中のダメージ・HP・破壊・復活（次の版）
- 発射の閃光と音

## [0.4.0] - 2026-11-17

### 追加

- 車両同士の簡易衝突：各オーナーが、物理の更新の最初に、自分の車両の速度だけを直す。相手へ寄る分を止め、重なった深さに応じて上限つきで押し返す。相手の車両も位置も直接は動かさず、同期の形式と同期変数は変えない
- 当たる位置：自分が持つ車両は今の位置、ほかの人の車両は最新の状態を今の時刻まで進めた位置（表示の位置とは少し違う）。止まった印のない状態が 1 秒より古い相手とはぶつからない
- 押される車両：押す加速が自分のブレーキより強い間だけ、車輪の張り付きを外して動く（WheelCollider は、駆動していない車輪を低速でその場に張り付かせるため）。横からは押されない
- 設定：「接触」の止める速さ・押し返す強さ・押す加速の上限。どれも Play 中に再適用できる
- デバッグ UI：オーナーの画面に `Contact`（重なっている相手の数）と `Stale`（状態が古くてぶつからない相手の数）

### 変更

- 設定アセットの版を 4 にした。版 1〜3 の設定は、開いたときに版 4 へ移る（前の値と参照はそのまま、足した項目は既定値）。ファイルに書き戻すのは、次に保存したとき
- 生成：同期の Udon に、接触に使う車体のコライダーの参照を足す。前に生成した車両は、「生成」をやり直すと接触が入る
- 同じ人がオーナーの車両同士も、すり抜けずにぶつかって止まる（通常の物理の当たりは今までどおり外したまま）

### 既知の制限

- 既定値（駆動のトルク 12000・停止中のブレーキのトルク 20000）では、戦車で止まった戦車を押せない。押せるようにするには、停止中のブレーキのトルクを駆動のトルクより小さくする

### 未実装

- 砲塔の操作・射撃

## [0.3.0] - 2026-11-16

### 追加

- 車体の同期（`YakimaTankVehicleSync`）：乗った人が車両のオーナーになり、オーナーの画面だけで走行を計算して、位置・向き・速度を送る。ほかの人の画面では、届いた状態を少し遅らせて補間し、届かない間は上限まで先へ進めて見せる。止まったら最後の状態を 1 回送り、後から入った人にも止まった位置が見える
- 乗るときの所有権：座ったらオーナーになってから操作できる。3 秒たってもオーナーになれないとき、座ったままほかの人がオーナーになったときは降ろす。運転手を同期し、後から入った人の画面でも、乗っている間は乗車の判定を無効にする
- シーンの車両の一覧（`YakimaTankVehicleRegistry`）：管理用のルートの下に 1 つ。配置で作り直し、手で置いた車両はウィンドウの「シーンの車両一覧を更新」で入れる。合わなければウィンドウに Warning を出し、VRChat SDK のビルドを止める
- 設定：同期の「送る間隔」と「先読みの上限」。どちらも Play 中に再適用できる
- デバッグ UI：同期の状態（オーナーか、オーナーと運転手の ID、世代、送った回数・要求した回数、最新の状態の古さ、使わなかった状態の数）

### 変更

- 設定アセットの版を 3 にした。版 1・2 の設定は、開いたときに版 3 へ移る（前の値と参照はそのまま、足した項目は既定値）。ファイルに書き戻すのは、次に保存したとき
- 車両の Udon の同期方式を Manual にした（同じ GameObject の同期の Udon とそろえる。同期変数は持たない）。0.2.0 で置いた車両は、コンパイルのときに UdonSharp がシーンの側を直してシーンが未保存になるので、保存してから「生成」をやり直す。配置は、この UdonSharp の上書きを手の変更とみなさない
- 車両の `SetDriveInput` と共通操作値は、オーナーの画面でだけ効く
- 座席：運転の W・A・S・D（VR はスティック）で座席から降りないようにした。VRCStation の Disable Station Exit を有効にし、降りる入力（今はジャンプ。Desktop は Space、VR はジャンプのボタン）は座席の Udon が受ける。0.2.0 で生成した車両は、「生成」をやり直すと入る
- 乗車の判定：前後・左右を車体のコライダーより 5 cm 外に、高さをモデル全体より 5 cm 外にした。面が車体のコライダーと重なる所で乗れたり乗れなかったりするのと、砲身の下で車体の前に立つと乗れないのを直した。前に生成した車両は、「生成」をやり直すと入る
- デバッグ UI：車両に付いて行くときの位置の既定値を、車体から見て (-4, 2.5, 6) にした（前は (-2, 2.5, 3)）。シーンに置いたパネルも、Follow Position を変えていなければこの値になる
- 生成：ルートに同期の Udon を足す
- 配置：配置のたびにシーンの車両の一覧を作り直す
- 0.2.0 までにビルドしたシーン：配置・「シーンの車両一覧を更新」・VRChat SDK のビルドの前に、車両の中を指す型の古い Network ID を外す。ルートに同期の Udon を足すと記録した型と合わなくなり、そのままでは SDK のビルドの前処理が止まるため。外した分は、ビルドで SDK が新しい ID を付ける。外したらシーンを保存する

### 未実装

- 砲塔の操作・射撃・車両同士の衝突（車両同士はすり抜ける。次の版で入れる）

## [0.2.0] - 2026-11-14

### 追加

- 乗車と降車：戦車と同じ大きさの乗車の判定を Interact すると、砲塔の上の座席（VRCStation）に座る。誰かが座っている間は判定を無効にする。降りるのは VRCStation の標準（Desktop は Space、VR はジャンプ）で、その場で降りる
- 共通操作値（`YakimaTankControlState`）：入力の方法と車両の動きを分ける値。自分が座っている間、車両はアクセル × ギアで走る
- Desktop の操作：W・S で前進・後退、A・D で旋回、視点で砲の入力、左クリックで射撃の入力（砲と射撃は表示だけ）
- VR の操作：左グリップ＋ひねりで旋回、手前に引いて後退のギア、左トリガーでアクセル。右手で砲と射撃の入力（表示だけ）
- デバッグ UI（`Runtime/YakimaTankDebugPanel.prefab`）：共通操作値を箱の大きさで見せる。車両に付いて行くか、置いた場所に留まるかを選べる
- 設定：座席のずらしと、VR の操作の調整値。どちらも Play 中に再適用できる

### 変更

- 設定アセットの版を 2 にした。版 1 の設定は、開いたときに版 2 へ移る（走行・足回りの値と参照はそのまま、足した項目は既定値）。ファイルに書き戻すのは、次に保存したとき
- 生成：車体のコライダーと WheelCollider を `Walkthrough` レイヤーに置き、プレイヤーと当たらないようにした。VRChat のレイヤーの設定がないと検証で Error になる
- 生成：元のモデルのトリガーでないコライダーを、生成 Prefab の中で無効にする（元のアセットは変えない）。検証で一覧を Warning に出す
- 検証：砲塔の対応がないと Warning（座席を車体に置く）。「砲塔は記録だけ」の Warning はなくした
- 配置：入れ物の中の車両を、子の順番ではなく生成 Prefab のインスタンスで見分ける。その車両を指すデバッグ UI を 1 枚まで許す（ほかの追加物は今までどおり止める）

### 修正

- 生成：車体自身にメッシュがない（メッシュのない親を車体に選んだ）とき、車体のコライダーが砲塔と砲身の先まで張り出していた。子のメッシュから求めるときは、砲塔と砲身を除く。除くとメッシュが残らない車体は、検証で Error になる
- 生成：砲塔自身にメッシュがないとき、座席の自動の位置が砲身の分だけ前へずれていた。子のメッシュから求めるときは、砲身を除く
- Play 中の出し直し：前の車両を表示していたデバッグ UI が、消えた車両を指したまま止まっていた。新しい車両につなぎ直す

### 未実装

- 砲塔の操作・射撃・同期（この版は各自の画面だけで動く）

## [0.1.0] - 2026-11-13

### 追加

- 車両の走行（`YakimaTankVehicle`）：前進・後退・旋回・制動、最高速度、設定の再適用と最初の位置への戻し
- セットアップウィンドウ（Tools → YakimaTank → Setup）と設定アセット：モデルの階層から車体と転輪を選び、検証して生成する
- 生成 Prefab：元のモデルを入れ子のまま置き、Rigidbody・車体の BoxCollider・転輪ごとの WheelCollider・車両の Udon を足す。生成し直しても GUID と中のオブジェクトを保ち、保存の後の確認で失敗したら前の Prefab に戻す。出力先にこのツールで作っていない Prefab があれば上書きしない
- シーンへの配置：最初のスポーン地点の前方に 1 台置く。2 回目からは同じ車両を使い、手で直した所があれば変えずに止める
- Play 中の調整：再適用・出し直し・作業値を設定に保存

### 未実装

- 砲塔の操作・射撃・同期・乗車と入力の割り当て（砲塔と砲身は設定に記録するだけ）
