## 1. 内容

専用ウィンドウで戦車モデルをセットアップし、VRChat 上で 1 人で走行・射撃・戦車同士の戦闘ができる状態にする。

### 1.1 走行

- 前進・後退・旋回・ブレーキ。
- 初版は WheelCollider 方式。後から別の走行方式に切り替えられる設計にする。
- カジュアルな操作感を優先する。衝突による細かな挙動は対象外。

### 1.2 操作と乗員

- 初版は 1 人で操縦と射撃を行う。後から複数人の乗車を足せる構造にする。
- VR の操作案：

| 操作 | VR |
| --- | --- |
| アクセル | 右トリガー |
| ブレーキ | 左トリガー |
| 旋回 | グリップ入力でその方向に旋回 |
| 砲塔・砲身 | グリップを握って操作 |
| 射撃 | トリガー |

- PCVR と Desktop での操作を確かめる。

### 1.3 射撃とダメージ

- 砲弾の発射・着弾・ダメージ判定。戦車同士の戦闘に対応する。
- 初版は HP を基準にした簡易な方式。HP が 0 になると爆発・破壊し、復活できる。

### 1.4 同期

- 車両の移動・砲塔・射撃・破壊状態を同期する。

### 1.5 アニメーションとサウンド

- 転輪：走行速度に応じて回す。
- 履帯：シェイプキーで速度を表す。
- サウンド：複数の WAV 音源を混ぜて鳴らす。
- 後で検討：サスペンション、履帯の上下動、複数軸の車両、波形の動的な生成。

### 1.6 専用セットアップウィンドウ

Unity Editor 上で戦車モデルを指定し、必要な設定をまとめて行うウィンドウ。モデルを指定して、少ない操作で走行・射撃できる Prefab を作れることを目標にする。

- 車体・砲塔・砲身・履帯・転輪の登録
- Rigidbody・WheelCollider などの設定の支援
- 走行性能・砲撃性能の設定
- 必要な Udon コンポーネントの自動配置と設定
- セットアップ内容の検証

### 1.7 優先順位

| 優先度 | 内容 |
| --- | --- |
| P0 | WheelCollider による走行 |
| P0 | 砲塔の操作・射撃 |
| P0 | 戦車同士のダメージ・破壊 |
| P0 | ネットワーク同期 |
| P0 | 専用セットアップウィンドウ |
| P1 | 転輪・履帯のアニメーション |
| P1 | エンジン音・射撃音 |
| P2 | 複数人の乗車・高度な物理の演出 |

### やらないこと（初版）

- 複数人の乗車と役割分担
- 高度な物理の表現（衝突の細かな挙動・サスペンションなど）
