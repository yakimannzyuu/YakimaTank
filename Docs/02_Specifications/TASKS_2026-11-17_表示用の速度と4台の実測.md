## メモ

- 計算のテストは先に書き、仮の実装で 3 件とも正しい理由で失敗するのを確かめてから実装した。
- PlayMode は、値を返す Udon の関数を `SendCustomEvent` で呼び、UdonSharp が返す値を置く変数（`__0_関数の名前__ret`）を読む。SDK の UdonSharp の名前の付け方に頼るので、変数がなければテストが失敗して分かるようにした。
- ClientSim は、ワールドのオブジェクトの Manual の同期を送らない（OnPostSerialization を呼ばない）。送った大きさは、テストが OnPostSerialization を呼んで確かめた。VRChat での実際の大きさは 1.3 で測る。
- デバッグ UI の Prefab の最初の文字（生成で入る `Bytes` のない文字）は、実行中に書き換わるので作り直していない。
- レビューの直し：表示用の速度の計算の「状態がない」の分岐が実行中に通らなかった（呼ぶ側が先に 0 を返していた）ので、呼ぶ側で状態の有無を渡すようにした。1.3 の手順に、操作する場所と順番、結果の表を足した。
- 直さなかったレビューの提案：送った大きさは所有権が移っても前の値が残る（「最後に送れた大きさ」として出す。測るときは自分が乗ってオーナーになってから見る）。Bytes の最大値は足さない（場面ごとに 1 分ほど見て、変わり方は書き留める）。テストが UdonSharp の返す値の変数名に頼る所は、名前の組み立てを 1 か所にまとめ、なければ失敗するのでそのままにした。
