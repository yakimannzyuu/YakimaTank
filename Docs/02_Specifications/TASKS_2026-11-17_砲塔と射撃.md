## メモ

- 1.10 の 1 つめ：車体と武器の所有権をほかの人にしてから座ると、続けて両方を取り、両方の通知が来て入力が有効になった（ClientSim の PlayMode）。
- 1.10 の 3 つめ：座ったまま砲塔を回すと、座席が位置の参照に付いて行き、向きは車体のまま、座った人も付いて行った（ClientSim の PlayMode）。
- UdonSharp がコンパイルのときに、シーンに置いた車両の Udon に新しい項目を書き足して、開発シーンが未保存になる（0.3.0 と同じ）。連携は未保存のシーンがあると要求を断るので、ユーザーに保存か破棄を頼む。
- ボーンで回すモデルは、メッシュが Skinned Mesh で、すべて同じルートのボーンを持つ。メッシュは読めない（Read/Write が無効）ので、重みからボーンとメッシュを結べない。
