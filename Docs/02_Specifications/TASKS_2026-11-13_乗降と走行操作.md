## メモ

- 部品の置き場所：
  - 共通操作値と Desktop・VR の入力は、ルートの子 `Controls` に置く。ルートには車両の Udon だけを残し、0.3.0 で車両の Udon を Manual にするときに、同じ GameObject で同期の方式が混ざらないようにする。
  - 座席は砲塔の子 `Seat`（VRCStation と座席の Udon）。座席の向きは車体にそろえ、ずらしは車体から見た向きで足す。
  - 乗車の判定はルートの子 `Boarding`（`Default` レイヤーのトリガー）。
- 座席の Udon は `NoVariableSync`。座席の出入りは VRChat が同期するが、`None` の Udon の上では VRCStation が他の人に正しく伝わらないことがあるため、ネットワークの対象にしておく。同期変数は持たない。
- 純粋な計算（Desktop・VR の変換、視点、走行への変換、ゲージ）は、各 Udon の静的な関数にして EditMode で確かめる（0.1.0 の走行の計算と同じ形）。U# の自作の関数は out 引数を使わない。
- デバッグ UI の Prefab は、Editor のビルダー（`YakimaTankDebugPanelBuilder`）で作ってパッケージに入れる。作り直すときも同じビルダーを使う。
- 開発ワールドの更新が置くパネルは、パッケージの Editor の処理（共通の配置処理の後に呼ぶ）で置き、パッケージのテストで 2 回の更新を確かめる。
