# 0004. VPM 配布はリリース時に整える

- 状態：承認
- 日付：2026-11-12
- 関連：[0001](0001-develop-package-under-assets.md)・[0003](0003-public-from-start-git-url.md)

## 背景

最終的には VCC から入れられるようにする。それには、配布用の zip を作って公開する仕組みと、VPM リスト（`index.json`）を公開する仕組みが要る。

## 決定

- VCC 向けの配布の仕組みは、正式リリースのとき（2026 年 12 月の予定）に整える。それまでは作らない。
- 今は手戻りを防ぐ準備だけをする。`package.json` に `vpmDependencies` を書き、変更履歴をパッケージの `CHANGELOG.md` に残す。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| リポジトリを作るときに配布の仕組みも作る | 開発中は git URL で足りる（[0003](0003-public-from-start-git-url.md)）。中身ができる前に配布の仕組みを保守することになる |

## 結果

- 良くなること：最初の作業が軽くなり、ギミック本体の開発に早く入れる。
- 引き受けること（欠点・制約）：リリース前に、配布の仕組みを作って確かめる時間を取る必要がある。

## 未決事項

| 何を | なぜまだ決めないか | いつ決めるか（きっかけ） |
|---|---|---|
| 配布の仕組みの作り方（VRChat 公式の template-package を元にするかなど） | 配布をまだ始めないため | リリースの準備を始めるとき |
| `.unitypackage` も配るか | 同上 | 同上 |
