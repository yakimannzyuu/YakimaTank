# 0003. 開発中から公開し、確認版は git URL で配る

- 状態：承認
- 日付：2026-11-12
- 関連：[0001](0001-develop-package-under-assets.md)・[0004](0004-vpm-at-release.md)

## 背景

開発中の版を、ほかの人に動作確認してもらいたい。最終的にはソースを公開する予定なので、初めから公開しておけば見てもらう手間が少ない。

## 決定

- リポジトリは開発の初日から公開にする。
- 開発中の版は、Unity Package Manager の git URL（`https://github.com/yakimannzyuu/YakimaTank.git?path=/Assets/Yakimannzyuu/YakimaTank`）で配る。main に取り込んだ時点で、最新版を取得できる。
- 非公開のメモ（`Docs/00_Memo/`）は Git に入れない。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 正式公開までは非公開にする | 動作確認のたびに招待や添付が要る |
| 開発中から VCC 向けに配る | 配布の仕組みを先に作る手間が大きい（[0004](0004-vpm-at-release.md)） |

## 結果

- 良くなること：URL を 1 つ渡せば、誰でも開発中の版を試せる。
- 引き受けること（欠点・制約）：
  - 履歴まで公開されるので、最初のコミットの前に、入れてはいけないものが無いかを確かめる。
  - UPM は取得したコミットを `Packages/packages-lock.json` に記録する。導入済みの版を更新するには、同じ URL を指定し直す。
