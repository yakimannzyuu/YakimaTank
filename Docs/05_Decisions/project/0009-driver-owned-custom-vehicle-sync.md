# 0009. 運転手が所有する独自同期と安定性優先の車両間衝突を採用する

- 状態：承認
- 日付：2026-11-13
- 承認：ユーザーが同日のチャットで「推奨の通りで決めてください」と指示。
- 関連：ADR 0008 の未決事項「車両の同期の方式」を決める。[SPEC_2026-11-13_車両物理同期と簡易衝突.md](../../02_Specifications/SPEC_2026-11-13_車両物理同期と簡易衝突.md) と同時に追加。

## 背景

同時に 4 台程度の戦車が走行する想定で、運転入力への反応を確保したい。壁との衝突は必要で、車両同士はゆっくり押せるとよいが、細かな物理再現より安定性を優先する。

車両ごとに運転手が所有すると、相手の位置は通信で遅れて届く。相手の表示を補正する移動が通常の物理衝突に入ると、不自然な反動が起こり得る。非オーナーを kinematic にするだけでは、他の Rigidbody への作用はなくならない。

## 決定

- 運転手をオーナーとし、オーナーだけが自車の走行と物理を計算する。車体の状態を Udon 同期変数で送り、非オーナーは補間と短時間予測を行う独自同期とする。
- 壁・地面は通常の物理、車両同士は各オーナーが自車だけへ適用する専用の簡易衝突とする。短いめり込みを許容して反力と補正を制御し、跳ね上がり・乗り上げ・振動を抑える。
- 無人車は通常停止し、他車に低速で押されれば動ける。有人車はブレーキで押されにくくする。衝突で所有権を移さず、降車後は直前の運転手が所有を続ける。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 全車両を 1 人のオーナーに集約する | 物理計算はまとめられるが、他の運転手の操作に通信遅延が入る |
| 非オーナーを kinematic にするだけで通常の車両衝突に任せる | kinematic でも他の Rigidbody を動かす。遅れた位置の補正から反動が発生し得る |
| 衝突時に車両の所有権を移す | 運転手の操作権限と競合し、接触中に所有者交代が繰り返される原因になる |
| 全員が同じ入力から車両物理を再現する | 地面との接触や時間刻みの差が蓄積し、状態を一致させる負担が大きい |
| 車両同士を常にすり抜けにする | 押す・ぶつかって減速する体験を満たさない |
| 車両同士の反力を毎フレームのネットワークイベントで送り合う | 遅延と順序、重複適用の管理が増え、継続的な接触処理が通信の到着に依存する |

## 結果

- 良くなること：運転手の操作をローカルで反映し、戦車同士の接触を安定性優先で調整できる。専用セットアップから同じ構成を生成する。
- 引き受けること（欠点・制約）：各クライアントで衝突時刻や見え方に差があり、短いめり込みは残る。厳密な運動量の保存や車両の乗り上げは目的としない。壁際・密集・通信遅延時の実機検証が必要になる。
- この決定は設計方針の承認。コードの実装・実機検証の完了や実装着手の指示を意味しない。
