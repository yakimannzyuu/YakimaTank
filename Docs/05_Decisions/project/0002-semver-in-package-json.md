# 0002. 版は SemVer とし package.json を唯一の版とする

- 状態：承認
- 日付：2026-11-12
- 関連：rules-adr 0004 をこの案件では置き換える

## 背景

共通ルール（rules-adr 0004）は日付の版 `YYYY.M.N` を使う。この案件は VPM パッケージで、VCC と Unity Package Manager は `package.json` の `version` を SemVer として読み、依存の範囲指定（`>=1.0.0` など）にも使う。

## 決定

- パッケージの版は SemVer（`x.y.z`）にし、`package.json` の `version` だけに書く。
- `0.x` で開発し、正式公開で `1.0.0` にする。公開後は、互換を破る変更で major を上げる。
- 原本のルール版（`YYYY.M.N`）は原本の形式のまま残し、パッケージの版とは別に扱う。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 共通ルールどおり `YYYY.M.N` | SemVer の形式としては読めるが、major が年になり、互換を破ったかどうかを版から読めない。利用者の依存の範囲指定とも合わない |
| `package.json` とは別に版のファイルを置く | 書く所が増えて、揃え忘れる |

## 結果

- 良くなること：VCC・UPM・利用者が、版から互換性を判断できる。
- 引き受けること（欠点・制約）：共通ルールの 4 章・5 章をこの案件用に書き換えて持つため、原本を取り込むときに維持が要る（rules 13 章）。
