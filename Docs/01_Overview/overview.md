# YakimaTank の概要

VRChat 向けの戦車モデルを、簡単なセットアップで走行・射撃できるようにする汎用の Udon ギミックです。専用のセットアップウィンドウで導入が簡単なことを、いちばんの特徴にします。

| 項目 | 内容 |
|---|---|
| 初版の目標 | 2026 年 12 月末 |
| ソースコード | このリポジトリで公開（MIT） |
| 方向性 | カジュアルな操作感と、導入の簡単さを重視 |

## 初版でできること

専用ウィンドウで戦車モデルをセットアップし、VRChat 上で 1 人で走行・射撃・戦車同士の戦闘ができる。

| 分野 | 内容 |
|---|---|
| 走行 | 前進・後退・旋回・ブレーキ（WheelCollider 方式） |
| 射撃 | 砲塔の旋回・砲身の俯仰・発射・着弾判定 |
| 戦闘 | 戦車同士のダメージ判定・破壊・復活（HP による簡易方式） |
| 同期 | 車両の移動・砲塔・射撃・破壊状態 |
| 演出 | 転輪・履帯のアニメーション、エンジン音・射撃音 |
| セットアップ | 専用 Editor ウィンドウによる導入 |

## 将来に向けて

初版では基本機能の完成を優先します。次のものは、後から足せる構造にしておきます。

- 走行方式の切り替え
- 複数人での乗車と役割分担（操縦手・砲手・車長）
- トランスミッション
- 乗員用のアイテム・車長のギミック（地図・双眼鏡・無線など）
- 高度なダメージ・装甲のシステム
- サスペンション・履帯アニメーションの拡張

詳しい仕様は [仕様書の一覧](../02_Specifications/README.md) にあります。初版に向けた段階の案は [プロトタイプまでの全体設計](../03_Architecture/prototype-plan.md) にあります。
